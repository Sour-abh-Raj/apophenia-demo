# Stimuli

| File | What | Visibility |
|---|---|---|
| `faces/*.png` | 22 noise images (20 scored, 2 practice), opaque names | public (served at `/stim/faces/…`) |
| `private_faces/*-face.png` | the 5 embedded faces without noise, for the reveal | instructor/projector key, only from the walkthrough phase |
| `faces_manifest.json` | **answer key** for Task 1 (face present, centre, radii, contrast) | server only |
| `battery.json` | **answer key and data** for Tasks 2 and 3 (sequences, processes, chart data, categories, replication samples) | server only (chart points and flips are sent to participants one trial at a time, without labels) |

## Provenance and attribution

- **Faces in the Noise** is a classroom adaptation of the Noise Pareidolia Test: Yokoi et al. (2014), *Neuropsychologia* 56, 245–254; Mamiya et al. (2016), *PLoS ONE* 11(5): e0154713 (CC BY 4.0). The images here are **not** the published NPT images. They were generated by `scripts/stimuli/generate_faces.py` using the same construction principle (faces embedded in 1/f-type noise in a minority of images), because the figshare dataset (doi:10.6084/m9.figshare.3187669) could not be downloaded from the build environment. The faces are procedurally rendered, depict no real person, and are free of third-party rights.
- **Coin Sequences** and **Branch Data** are synthetic, generated by `scripts/generate-battery.ts` from fixed seeds.

## Regenerating

```bash
npm run generate:battery            # deterministic; byte-identical to the committed file
python3 scripts/stimuli/generate_faces.py   # needs numpy + Pillow; byte-identical output
```
Both are verified by `tests/unit/stimuli.test.ts`.

## Using the original NPT images instead (optional)

If you obtain the figshare files yourself, check their licence, then inspect every image to establish the face/no-face label and the face location by eye (the dataset's own documentation should be followed). Replace the files in `faces/` and write a `faces_manifest.json` with the same fields. Keep the labelling decisions in a written record **before** any class uses them, and keep calling the task an adaptation unless you also use the full 40-trial procedure.
